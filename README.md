## Deploy On GitHub Pages

1. Create a GitHub repository, for example `akshayhydrology.github.io` for a user site.
2. Upload the live site files and folders to the repository root.
3. In GitHub, go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root`, then save.
6. GitHub will publish the site at the Pages URL shown in the same settings panel.

For a user site named `akshayhydrology.github.io`, the homepage will be `https://akshayhydrology.github.io/`.
